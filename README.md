# shiba-db releases

Builds of [shiba-db](https://github.com/apitamr/shiba-db-releases/releases), a compact database client: PostgreSQL, MySQL/MariaDB, SQLite, DuckDB, SQL Server, ClickHouse, MongoDB and Redis.

Download the latest from [Releases](https://github.com/apitamr/shiba-db-releases/releases/latest):

- **Linux**: the AppImage (updates itself), the `.deb`, or the tarball with its `PKGBUILD` for Arch (`makepkg -si`)
- **Windows**: the `.msi` (updates itself)
- **macOS**: the `.dmg`

This repository holds the builds only; the app checks its latest release for updates.
