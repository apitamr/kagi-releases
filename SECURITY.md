# Security

Kagi keeps database passwords and connects to your servers, so security problems matter. Please report them privately, not in a public issue.

## Reporting a problem

Open a private report on this repository: **[Report a vulnerability](https://github.com/apitamr/kagi-releases/security/advisories/new)**. Only the maintainer sees it.

Include:

- the Kagi version and how it's installed (the .dmg, the .msi, the snap, .deb, Arch package, Flatpak or AppImage);
- your operating system;
- what the problem is and how to reproduce it;
- what someone could do with it.

You'll get an answer within a few days. Once it's fixed, the release notes say so, crediting you if you'd like.

## Supported versions

Only the latest release gets fixes. Kagi updates itself on Linux and Windows; on macOS, download the newest from the [releases](https://github.com/apitamr/kagi-releases/releases/latest).
